**SME Masterclass**

Workflows and demo data from the WIT-K AI Masterclass live build session, held online on 31 October 2026 by Women in Tech Kenya in partnership with n8n.

We took a small grocery wholesaler in Nairobi that runs on a notebook and an Excel sheet, and automated its sales, purchases, inventory, payments and reporting. Then we added an AI agent that takes customer orders in English or Swahili.

**Watch the session here**
https://drive.google.com/file/d/1tUwVaMsS6Si365K_GPpynAHk5OqNgKf_/view?usp=sharing

**What's in this repository**
workflows	- 13 n8n workflows as JSON files, ready to import
data - 10 CSV files of demo data for the Airtable base

**What you need**
- An n8n account: n8n Cloud or self-hosted.
- An Airtable account (the free plan works)
- A Gmail account, for the email workflows

**Get started**
Each workflow has an "About" note on its canvas explaining what it does and how to test it. Start with the data, then import the workflows and connect your own accounts.
